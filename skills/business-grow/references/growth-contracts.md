# Growth Contracts

## Acquisition test

```text
customer / offer version
channel hypothesis and evidence for access
permitted audience/data
qualified signal
named transitions + entity unit + denominator/window
budget/time/sales-effort limits
delivery/capacity guardrail
downstream value/economic signal
success / failure / inconclusive / stop
```

## Sales path

Distinguish person, account, opportunity and transaction. Record buyer/user/payer/approver, qualification criteria, actual decision process, sales effort and loss reasons.

## Continued value

Define cohort/start/continuation event/window, delivered-value signal, cancellations/refunds, cost to serve and expansion/referral event. Do not manufacture recurring value for a one-off exchange.

## Scale gate

Require supported channel signal, compatible attribution definition, delivery headroom, positive relevant contribution, fundable cash exposure and applicable authority/professional review. Unknown critical input blocks a confident scale recommendation.
