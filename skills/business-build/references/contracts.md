# Business Build Contracts

## Business brief

```text
decision/objective
context and authority
customer roles
problem / desired progress / alternatives
value / proof / limits
offer / price / payment / obligations
demand/sales hypothesis where relevant
delivery/capacity
economics/cash
continued value where relevant
evidence table
accepted decisions
material assumptions
next experiment/commitment
professional/approval blockers
```

Use only relevant fields. Missing material information is explicit.

## Evidence

```text
ID | statement | basis(observed/reported/derived/assumed/synthetic)
source + as-of/window | population/scope | method | limitations
```

## Offer

Customer/buying context; controlled deliverable; uncertain outcome; mechanism; scope/exclusions; time-to-value; price/unit; payment timing; obligations/remedies; proof; factual scarcity if any; approvals.

## Economics

Declare currency, unit/cohort, period, revenue, variable/direct cost boundary, acquisition/sales/support/refund costs, capacity, receipt timing, obligations and observed/forecast status. Contribution = revenue minus the explicitly supplied variable/direct costs. It is not whole-business profit.

## Assumption

```text
statement
basis
uncertainty + rationale
consequence_if_wrong + rationale
decision_affected
evidence
next_test_or_commitment
```

## Experiment

```text
assumption / hypothesis
decision that can change
target population/unit
method / cheapest adequate representation
primary signal + denominator
guardrails
confounders
success condition
failure condition
inconclusive condition
stop conditions
cost/exposure
authority/reviews
instrumentation checks
```

## Preservation

State accepted decisions and the fields/layers this task may change. Review dependent decisions when an upstream fact changes; do not automatically rewrite them.
