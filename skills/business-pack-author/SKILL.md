# Business Pack Author

Create business-model grammars, not industry labels.

## Rules

Prove an existing pack/core is insufficient. Define activation and incompatible cases. Specify only changed core behaviour. Include economics/cash/capacity semantics, exact showcase prompt and positive/negative/differential evals. Explicit project facts and reviewed constraints outrank pack defaults.

## Commands

`inspect-catalogue`, `research-business-model`, `define-specialisation`, `define-core-effects`, `build-pack-showcase`, `build-pack-evals`, `compare-core-vs-pack`, `validate-pack`.

This is a Stage 21 scaffold; implementation follows after the core vertical.
