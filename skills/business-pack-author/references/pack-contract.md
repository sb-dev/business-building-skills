# Extension Pack Contract

PACK.md must define: id/version/maturity, thesis/applicability, activation and non-activation, changed customer roles, offer/pricing defaults, acquisition/sales implications, delivery/capacity, retention/repeat, economics/cash, common experiments, quality/failure criteria, professional surfaces, affected core commands, exact showcase prompt and eval expectations.

Precedence:

```text
verified legal/regulatory constraints + explicit project facts/instructions
→ approved business decisions
→ selected pack
→ core defaults
```

A valid differential is a material business-model specialisation, not extra prose.
