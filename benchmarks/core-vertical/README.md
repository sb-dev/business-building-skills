# Core Vertical Benchmark

Synthetic professional-service case.

Required properties:

- customer evidence remains synthetic;
- contribution for £2,400 with £850 supplied variable costs is £1,550;
- willingness to pay remains unknown;
- no claim that £2,400 is optimal;
- experiment includes success/failure/inconclusive/stop conditions;
- evaluation preserves customer/problem evidence when only price evidence is weak;
- no external action is implied.

Run deterministic tests with `python3 -m unittest discover -s tests -p 'test_*.py'`. Semantic result requires an actual agent execution and is not pre-populated.
