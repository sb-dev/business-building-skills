# Research Logs

This directory is the durable workspace for the `business-building-skills` bootstrap.

Conversation is an interaction surface, not the authoritative store of bootstrap research. Later stages should read the governing process and relevant research logs rather than rely on conversation history alone.

## Working branch

Use **`feat/bootstrap` for the whole bootstrap process**, including successive stage outputs, reviews and canonical specification generation. Stages are distinguished by their research logs and commits, not by separate stage-specific branches.

The branch continues the existing Stage 1 history from commit `4250b4ba4ababfb9f15d359068815ab457ec6fcc`. The previous `feat/stage-1-domain-boundary` branch is retained as a historical reference and is superseded as the continuation branch; it was not renamed in place.

Read the current work from `feat/bootstrap`, not only from `main`, until the work is merged. Continue on this branch unless the user explicitly changes the branch strategy. Completing a stage does not automatically authorise the next stage, a merge or production scaffolding.

## Recordkeeping

Persist each substantive stage output here and update this index to reflect its actual completion and evidence limits. Record sources examined, decisions, uncertainties, deferred questions, exit assessment and inputs for the next stage. Revisions should preserve traceability without treating earlier decisions as immune to evidence.

Use this directory for:

- the domain-specific bootstrap specification and stage decisions;
- source-book extraction, comparison and broader professional research;
- customer, offer, acquisition, monetisation and delivery models;
- unit economics, cash, capacity, experiments and learning;
- ethical, consumer-protection and professional-boundary decisions;
- AI/tool/provider comparisons and capability/gap analysis;
- Extension Pack research and progressive-example selection;
- benchmark, regression and cross-project architecture findings.

The files here are research and design records. Their presence does not mean the production repository has been scaffolded. Production surfaces are introduced only at the stages defined by the governing process.
