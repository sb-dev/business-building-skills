## 7. Bounded evidence programme

The following is a complete next-evidence design. No recruitment, customer test or external action has occurred. Numeric recruitment or inference requirements belong to a later authorised study if its decision requires them; the finite record audits and qualitative diagnostics below make no statistical claim.

| Stage 8 experiment field | Case-specific design |
|---|---|
| assumption | A genuine additional paid service can coexist with the usable core and maintained contributor/maintainer obligations; interest does not prove this. |
| hypothesis | A bounded scope/rights/capacity review can identify one incremental value exchange whose obligations fit funded, explicitly committed work, or show why no new offer should proceed yet. |
| cheapest valid test | Audit existing three service engagements, maintenance/sponsor terms and task allocation first. This can reveal current infeasibility without building education content or a marketplace. If coherent spare capacity emerges, propose one truthful scoped offer test with an actual authorised buyer. |
| target population | The supplied service/maintenance obligations and distinct maintainer, contributor, sponsor and buyer roles; actual interviews or transactions need separate authority and access. |
| success failure signal | All new obligations must have permitted scope, a named willing payer where payment is claimed, funded/deduplicated work and dated capacity. An interest response remains interest; rights conflict or workload above the real limit challenges readiness. |
| guardrails | No relicensing, paid-core restriction, unilateral volunteer obligations, restricted-fund diversion, publication, contact, charge or marketplace launch. Keep existing customer and contributor rights and segregated funding. |
| duration sample | Review all supplied existing obligations in the 80-hour planning window and the full proposed service/funding horizon. A later offer test must state its own sales/fulfilment window; three existing customers do not establish statistical market prevalence. |
| confounders | Unmatched analytics windows, voluntary-labour assumptions, double-counted shared work, sponsor restrictions, paid-service selection bias, and changes to free-core access during a test. |
| decision rule | Known rights/capacity conflict: reject affected proposal and request a local repair. Coherent funded scope: propose only one bounded value test subject to the remaining gates. Missing role/rights/payment evidence: block relevant commitment. Inconclusive demand: retain uncertainty. Guardrail breach: stop affected action through its owner; preserve evidence and existing permissions. |

The learning record must preserve the hypothesis, this unexecuted design, supplied fictional observations, actual deterministic results, qualified interpretation, bounded decision, remaining unknowns and proposed next commitment. Do not backfill a prespecified rule into the inherited observations. Reconsider only affected dependencies after new evidence; retain source and accepted versions.
