# Contributing

Business Building Skills is evidence-preserving, provider-neutral and capability-shaped.

Before proposing a skill, command or Extension Pack:

1. identify the business-building responsibility and evidence gap;
2. show why an existing tool or current command does not already own it;
3. preserve facts, accepted decisions and professional constraints;
4. add the smallest relevant eval/fixture;
5. keep source-book material independently expressed and copyright-safe;
6. do not add provider credentials, customer personal data or fabricated benchmark results.

New packs must demonstrate a material core-vs-pack behavioural difference and include an exact showcase prompt plus negative/incompatible cases.

Run the repository validator and deterministic tests once Stage 22 implements them. Semantic benchmark results must identify the actual agent/model execution; never commit a hand-authored output as measured agent evidence.
